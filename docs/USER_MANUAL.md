# 卓声 · 用户手册

> 卓声（Zenith Audio）是一个作曲与编曲工具。本手册面向使用者；开发相关见
> `docs/ARCHITECTURE.md` 与 `docs/RUST_CORE.md`。

---

## 1. 界面总览

进入工程后从上到下依次是：

1. **菜单栏**（桌面）与**工具栏**——文件、编辑、视图、帮助；播放控制。
2. **A/B 对比条**——仅在开启 A/B 对比时出现。
3. **轨道区 / 通道机架 / 编排区**——工程的主工作区。
4. **底部传输条**——播放头位置、播放/暂停/停止、循环。

### 轨道类型

- **音频轨**：引用一个音频文件。
- **乐器轨 / 合成器轨**：承载音符，经内置合成引擎发声。

---

## 2. 打开与保存

- **打开**：`Ctrl+O`。旧格式工程（`.lgdf`、`.zap`）会在打开前提示将被升级；
  升级是**非破坏性**的——原文件不动，新格式只在你保存时写出。
- **保存**：`Ctrl+S`。工程以 LGDF v2.0 目录格式保存。
- **导出工程**：`Ctrl+E`。

---

## 3. 音符编辑（钢琴卷帘）

打开一条乐器轨的钢琴卷帘可编辑音符。

**网格与吸附**：工具栏切换吸附开关与分辨率（1/1 … 1/32、三连音）。

**音符工具**（工具栏 →「音符工具」）：

| 工具 | 作用 |
|---|---|
| 量化 | 把音符起点吸附到网格；可设强度 0–100%，保留演奏的 groove |
| 摇摆 | 把 off-beat 音符后移，产生三连音感觉；保留音符离网的偏移 |
| 力度斜坡 | 按时间顺序在起始力度与结束力度之间插值 |
| 力度随机 | 每个音符力度在设定范围内随机 |
| 压缩 / 扩展 | 以中值为中心收拢或拉开力度动态 |
| 移调 | 整体 ±1 或 ±12 半音 |

> 每次应用整段提交为**一步撤销**。撤销 `Ctrl+Z`，重做 `Ctrl+Shift+Z`。

---

## 4. MIDI 导入与导出

- **导入 MIDI**：`Ctrl+Shift+I`（音轨菜单）。SMF 0/1 均可；多轨文件会生成多条乐器轨，
  速度与拍号随文件设置。SMPTE 时基的 MIDI 会被明确拒绝，而不是错位导入。
- **导出 MIDI**：音轨菜单 →「导出 MIDI」。当前工程的样式会写成标准 MIDI 文件，
  可被通用音序器读取。

---

## 5. 混音器

通道机架提供每条通道的推子、声像、静音/独奏、效果槽与发送。增益以 **dB** 显示，
推子底部是精确静音。电平表显示峰值与 RMS，并有 3 秒峰值保持。

---

## 6. A/B 对比

视图菜单 →「A/B 对比」开启。开启时会拍下当前工程为 A，并复制一份为 B。

- 点 A / B 切换；或按 `Shift+Tab` 快速来回。
- 「复制到另一侧」把当前一侧的内容覆盖到另一侧（做出决定后采用）。
- 「退出 A/B」保留当前一侧。

适合对比「压缩器在 EQ 前还是后」这类只听感才能决定的问题。

---

## 7. 音频卡顿与自动降级

当实时负载过高（最常见于浏览器标签页），卓声会**自动停用最耗性能的功能**并
**在页面顶部显示持久警告条**：

- 警告**不会自动消失**——必须由你处理。这样你不会误以为问题已解决。
- 警告条会列出被停用的功能（如卷积混响、过采样失真、发送/返回总线）。
- 可点：
  - **恢复**——性能持续健康后，逐级恢复；
  - **仍要启用**——强制恢复全部功能，但警告保留（引擎并没有真的变快）；
  - **降低采样率 / 增大缓冲**——最常真正解决问题的两个调整。

被停用的功能在界面上会置灰。

---

## 8. 快捷键

见 `docs/SHORTCUTS.md`。常用：`Space` 播放/暂停、`Ctrl+Z` 撤销、`Ctrl+S` 保存。

---

## 9. 从旧版本迁移

旧的 `.zap` 与 `.lgdf` 工程可以直接打开。打开前会显示检测到的格式，并说明将升级为
当前格式；再次强调：**原文件不会被修改**，升级结果只有在保存时才写出。

如果工程来自更新版本的卓声，会提示需要更新应用。
