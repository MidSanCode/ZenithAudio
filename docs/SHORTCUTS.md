# 卓声 · 快捷键表

> 本表由 `lib/core/shortcuts.dart` 的 `kShortcuts` 单一来源维护。改动快捷键时先改该
> 文件，再更新本表；`test/shortcuts_test.dart` 会读取本文件并逐一核对，阻止两者漂移。
>
> "组合"列按 **Windows / Linux** 书写。macOS 上将 `Ctrl` 显示为 `⌘`、`Alt` 显示为
> `⌥`，分隔符省略（如 `⌘S`、`⇧⌘Z`）。

| 作用 | 组合 | 作用域 |
|---|---|---|
| 新建工程 | `Ctrl+N` | 全局 |
| 打开工程 | `Ctrl+O` | 全局 |
| 保存工程 | `Ctrl+S` | 全局 |
| 导出工程 / 混音 | `Ctrl+E` | 全局 |
| 退出 | `Alt+F4` | 桌面 |
| 撤销 | `Ctrl+Z` | 编辑器 |
| 重做 | `Ctrl+Shift+Z` | 编辑器 |
| 添加音轨 | `Ctrl+T` | 编辑器 |
| 导入音频 | `Ctrl+I` | 编辑器 |
| 导入 MIDI | `Ctrl+Shift+I` | 编辑器 |
| 播放 / 暂停 | `Space` | 编辑器 / 钢琴卷帘 |
| A/B 对比切换 | `Shift+Tab` | 编辑器（A/B 模式） |
